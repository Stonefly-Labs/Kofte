# Architecture decision records

Use `NNNN-short-title.md` for a consequential choice. Read the [architecture decision backlog](../architecture.md#17-adr-backlog-and-unresolved-design-choices) first; do not invent a decided outcome during repository setup.

```markdown
# NNNN: Decision title

**Status:** Proposed | Accepted | Superseded
**Date:** YYYY-MM-DD
**Spec:** Link to the affected spec

## Context

Problem, constraints and canonical requirements.

## Decision

Chosen approach and rationale. Identify any required constitutional amendment.

## Alternatives

Options considered and why they were not chosen.

## Consequences

Tradeoffs, compatibility, migration/rollback and validation.

## Approval

Human decision and PR link. Link any superseding ADR.
```
